## 先说你做对了什么

- **情绪图选得好**："下午四点的斜阳穿过高窗照进泳池"，这一个画面就把梦核的温柔与空旷说清楚了。
- **场景有叙事道具**：救生椅、扶梯、长椅、通往出口的绿门，都在讲"这里刚刚有人离开"。这一点比很多纯程序化的原型做得好。
- **计划书的机制都接上了**：穿模弹回会扣清醒度；15:00 后要走到北侧绿门才能通关；有温柔模式开关和触屏摇杆。

问题不在于缺少想法，而在于**画面没有被当成一个完整的世界来对待**。下面逐条说明。

## 九处批改（对应标注图编号）

### 1. 游戏被装进了一个深色仪表盘

- **现状**：顶部有导航栏，右侧是"梦游监测 LIVE"面板，下方还有操作指南条。游戏只占屏幕约 45%。
- **为什么不对**：近黑背景（`--base:#101613`）加薄荷绿点缀，是 AI 生成界面最常见的模板外观。梦核是明亮、柔光、过曝的，深色外框会把整个梦压暗。游戏应该就是页面本身，而不是页面里的一个组件。
- **怎么改**：
  - 让 canvas 铺满视口（`position:fixed; inset:0`），删掉导航栏、侧栏和底部操作条。
  - 操作说明只在标题页出现一次。
  - 页面背景色取画面的主色（暖奶油色），不要用近黑。

### 2. 等宽字体的"DREAM TIME"

- **现状**：时钟用的是 `ui-monospace, Consolas, Courier New`，装在一个深色卡片里。
- **为什么不对**：等宽字体传达的是终端、黑客、数据面板的气质，跟梦没有关系。
- **怎么改**：
  - 时钟去掉卡片底，直接浮在画面左上角。字体用 Nunito 300，约 38px，配一层白色柔光 `text-shadow`。
  - 标题用 Noto Serif SC。
  - 伤害数字用 Caveat 手写体，中文回退到 Long Cang。
  - 全部从 Google Fonts 加载，并写好回退字体。删掉 `Times New Roman` 和 `Microsoft Yahei` 这类默认字体。

### 3. 半透明的绿色长条"隔板"

- **现状**：`partition()` 在插画上画了两块半透明绿色的平行四边形。
- **为什么不对**：它们和插画的透视、材质、光照都不一致，看上去像没清理掉的调试占位块。
- **怎么改**：二选一。
  - 删掉它们，障碍只用插画里本来就有的物体（池边、柱子、救生椅）。
  - 或者把它们画成和插画同透视、同光向的实体，例如瓷砖矮墙：有顶面、侧面，有朝右下方的投影。

### 4. 气球人画成了灰色的炸弹

- **现状**：灰黑色渐变的椭圆，加一根细线。
- **为什么不对**：计划书里的气球人是**粉彩色、笑得太宽的笑脸**。梦核的诡异来自"可爱却不对劲"。灰色气球只剩下阴沉，像地雷。
- **怎么改**：
  - 随机粉彩色相，饱和度约 0.6，亮度约 0.8。
  - 用两个竖椭圆当眼睛，配一道过宽的弧线嘴巴，再加一个高光点。
  - 无脸同学改成浅色制服（淡紫灰），配深蓝立领，脸部是一块空白的肤色。

### 5. 主角只有约 25 像素高

- **现状**：在 450px 高的画布里，主角大约 25px 高。在下午的光斑里几乎找不到。
- **为什么不对**：割草游戏的第一审美是"满屏敌人时一眼找到自己"。
- **怎么改**：
  - 角色高度不低于画布高度的 7%，也就是 450px 画布里至少 32px，并提高 `zoom` 让镜头更近。
  - 主角加一圈 1.5px、60% 不透明度的深紫墨色描边（可以先用 `ctx.filter` 或 `shadowBlur` 画一层描边再画本体）。
  - 主角身上带一团暖色的小夜灯光晕，要比周围地面更亮。

### 6. 文案说"水面还在晃动"，水却是静止的

- **现状**：水是插画里的静态像素。
- **为什么不对**：文案对画面的承诺没有兑现，玩家会立刻察觉"这只是一张图"。
- **怎么改**：
  - 画一张与插画对齐的**水面遮罩**（黑白 PNG）。
  - 在遮罩范围内，用 `globalCompositeOperation = 'screen'` 叠加一层缓慢漂移的焦散纹理：可以是两层不同速度平移的程序化焦散图，透明度约 0.25。
  - 再加极轻的横向波纹位移。
  - 窗户投下的光柱也要每 8–12 秒缓慢移动一次明暗。

### 7. "梦游监测 LIVE"面板

- **为什么不对**："监测""LIVE"是医院或监控系统的语汇，会把玩家拉出梦境。
- **怎么改**：
  - 血条改成跟随主角脚下的一条细线。
  - 经验条改成屏幕顶端一道慢慢亮起的地平线。
  - 清醒度改成主角脚下的一圈柔光环。
  - 等级和击杀数放在时钟下方，用小字。
  - 其余信息放进暂停页，暂停页做成一张档案纸片。

### 8. 同一个信息出现了四次

- **现状**："DREAM LAYER / 00""梦层 L0""L0 / POOLROOMS"，再加上大标题，都在说"你在 L0"。
- **为什么不对**：重复不会增加信息，只会增加噪音，削弱真正重要的东西。
- **怎么改**：梦层名只在入梦时出现一次，做成 2.5 秒后淡出的标题卡；之后只在时钟下方用一行小字保留。

### 9. 时间戳日志"梦境记录"

- **为什么不对**：`00:18 梦境升级 · 小夜灯` 这种格式是开发者控制台的语言。
- **怎么改**：删掉日志。重要事件用屏幕顶部中央一条弹簧动效的短提示，2.5 秒后消失，并且要写成梦里的话，例如"气球从四面八方飘过来了"。

## 门之抉择（见 `gpt-v0.1-doors.jpg`）

- **现状**：画面整体压暗，三张橄榄色、石板色的长方形卡片，每张一张小拍立得，选项**永远是小夜灯、旧照片、糖果这三个**。
- **为什么不对**：
  - 压暗遮罩让梦变沉，应该是**变亮、起雾**。
  - 长方形卡片没有"门"的感觉：没有拱形，没有门框，没有门缝里漏出的光，也没有开门的动作。
  - 固定三选一会直接取消肉鸽的构筑乐趣。
- **怎么改**：
  - 遮罩改成奶油色雾面：`rgba(247,243,236,.85)` 加 `backdrop-filter: blur(5px)`。
  - 门做成拱形，带门框、黄铜门把和凸起的门板。
  - 悬停时门绕铰链转开约 26°，门框发出暖光，地面出现一道光。
  - 选中后门转开约 104°，然后接一段 0.3 秒的白光过场。
  - 门背面的拍立得要隐藏（`backface-visibility:hidden`）。
  - 显示"新"或"Lv N"标记、一句效果说明和标签。
  - 从加权随机池里抽三个选项，并提供"再睡五分钟"（重抽）和"忘掉它"（放逐）。

## 打击感（目前几乎没有）

| 需要补的反馈 | 规格 |
|---|---|
| 受击闪白 | 80ms |
| 击退 | 被击中的敌人后退一小段 |
| 伤害数字 | 手写体；暴击用粉色、字号加大 |
| 死亡爆散 | 10–14 片花瓣或彩纸，带重力、旋转和横向飘落 |
| 星屑拾取 | 螺旋磁吸；连续拾取时音高沿五声音阶上行 |
| 光环脉冲 | 从中心向外扩散一道光波 |

## 整屏绿色叠加

- **现状**：`paint()` 每帧都执行 `fillStyle = '#84c7ba15'; fillRect(...)`，整屏叠一层绿色。
- **为什么不对**：这层绿和底图的橄榄色调叠在一起，让画面发闷。
- **怎么改**：
  - 删掉这层叠加。
  - 清醒度不要用整屏染色来表达，而是用：低清醒度时饱和度略升、边缘出现奶白色晕光、画面轻微"呼吸"缩放（±0.6%）。

## 光照一致性（L5 级细节）

插画的光是从左上方的高窗打进来，照向右下方。

- 所有角色的投影都改成**朝右下方的长椭圆**。
- 角色走进光斑区域时，本体提亮 10–15%：用一张光斑亮度遮罩采样脚下的亮度，再通过 `ctx.filter = 'brightness(...)'` 调整。

做到这两点，贴图才算"站在这张画里"，而不是浮在画上面。

## 改造顺序

按对画面影响从大到小排列：

1. **P0**：
   - 全屏化，拆掉仪表盘（第 1、7、8、9 条）；
   - 换字体（第 2 条）；
   - 删掉绿色隔板和整屏绿色叠加（第 3 条）；
   - 重画角色，包括比例、描边、粉彩气球人和浅色无脸同学（第 4、5 条）。
2. **P1**：
   - 让水面和光柱动起来（第 6 条）；
   - 重做门之抉择，加入随机池；
   - 补上打击感；
   - 角色投影方向和光斑提亮。
3. **P2**：
   - 用一张与插画对齐的可行走遮罩图替代手写的斜线碰撞；
   - 长期目标：把插画拆成同风格的可拼接模块（地砖、池段、墙段、道具），让地图可以无限延伸。目前 1440×960 的固定小地图不支撑 15 分钟的割草节奏。

## 验收标准

每一轮改完，截三张图：标题、战斗中期（同屏 150 个以上敌人）、门之抉择。然后逐一检查：

- [ ] 第一眼看到的是主角；
- [ ] 画面里没有任何近黑色块，阴影是冷蓝灰；
- [ ] 中文没有落到系统黑体，没有等宽字体；
- [ ] 水面和光柱在两张相隔 3 秒的截图里看得出变化；
- [ ] 门之抉择让画面变亮而不是变暗，悬停时门会开；
- [ ] 遮住 HUD 后，战斗截图可以直接当宣传图。

没有截图，就不能声称完成。
