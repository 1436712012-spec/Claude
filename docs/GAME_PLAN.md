# 《梦隙 NOCLIP BLOOM》游戏计划书 v0.1

> 类型：俯视角割草肉鸽（Survivors-like）｜题材：梦核 × 后室式阈限空间 × 异常收容档案｜平台：Web 优先，后续桌面端

---

## 0. 一句话

一个睡不醒的孩子“穿模”掉出了现实，在无人的游泳馆、黄色办公层和打烊的商场里，用童年的小物件抵挡潮水般的梦魇，并把遇到的异常一件件写进档案——直到在档案最后一页读到自己的编号。

## 1. 设计支柱

1. **温柔的诡异**：恐惧来自“不对劲”，而不是血腥或跳吓。画面始终是柔光、低饱和、怀旧的，美到让人想截图。
2. **一局 15 分钟的爽**：保留同类游戏“移动即战斗、构筑滚雪球、满屏清怪”的核心快感，上手 10 秒内进入战斗。
3. **空间本身是玩法**：地图有墙、有走廊、有夹层，而不是一片空地。玩家可以“穿模”穿墙，敌人不行。
4. **每个异常都是一条规则**：Boss 不是更厚的血条，而是一个需要读懂的小谜题，破解后收进档案。

## 2. 世界观

- **梦游者**：玩家角色。现实里一直没有醒来，在梦里不断穿模下坠。
- **静默档案馆**：一个只在梦里存在的机构，用泛黄的打字机文档记录梦中异常，等级分为「温顺 / 游离 / 失眠」三级。
- **梦层**：每一局是一个梦层。局内时钟从 00:00 走到 07:00（现实 15 分钟），07:00 闹钟响起即为醒来（通关）。
- **反转**：通关所有梦层后，档案馆最后一份文件是「NB-000：做梦的人」。玩家一直在收容的，是自己不愿醒来的理由。

叙事全部通过档案碎片、场景细节和异常的行为传达，不使用大段过场。

## 3. 核心循环

**局内**：移动走位 → 武器自动攻击 → 击败梦魇掉落「星屑」（经验）→ 升级时三选一 → 触发异常事件并收容 → 07:00 前的“苏醒潮”坚持 60 秒 → 走出出口门。

**局外**：带回「梦尘」与收容物 → 在档案馆（一间漂浮在云上的卧室）解锁角色、永久强化、新梦层与档案文本 → 再次入睡。

## 4. 独创机制

### 4.1 穿模（Noclip）

- 空格冲刺 0.35 秒，期间无敌并可穿过墙体，冷却 6 秒。
- 墙后有只能穿模进入的「夹层」，藏着宝箱、闹钟和档案碎片。
- 若冲刺结束时卡在墙内，会被弹回原位并损失清醒度，用来惩罚盲穿、奖励读图。
- 可升级分支：残影造成伤害 / 两段冲刺 / 穿墙瞬间冻结周围敌人。

### 4.2 清醒度（Lucidity）

和生命值并列的第二资源，范围 0–100，是本作的核心风险旋钮。

| 区间 | 名称 | 效果 | 画面表现 |
|---|---|---|---|
| 70–100 | 清醒 | 正常 | 清晰、偏冷 |
| 30–70 | 浅眠 | 经验 +25% | 泛光增强、颜色变奶油 |
| 0–30 | 深梦 | 经验 +60%，敌伤 +40%，武器可「梦化」进化，隐藏门出现 | 画面柔焦、轻微呼吸畸变、远处出现不该有的东西 |

清醒度会自然流失，部分敌人会吸取，拾取「闹钟」可回复。画面风格直接由这个数值驱动，所以美术本身就是玩家能读到的反馈。

### 4.3 门之抉择（升级界面）

升级时时间静止，雾中浮现三扇门，每扇门上贴着一张道具拍立得。鼠标悬停时门微微开启，门缝里漏出光。

- 重抽：「再睡五分钟」
- 放逐：「忘掉它」
- 稀有升级会以一扇“不该出现在这里”的门出现，比如一扇泳池里的门。

### 4.4 共鸣标签

每件道具带 1–2 个标签：光 / 纸 / 声 / 水 / 屏幕 / 童年。同标签集齐 2 件和 4 件时分别激活小加成和大加成。例如「声 ×4」：所有武器每第 8 次攻击变为双倍“节拍”。这样构筑除了数值之外还有一个方向感。

### 4.5 异常收容事件

局内第 3、7、11 分钟各出现一个异常，第 15 分钟为苏醒潮。完成收容可获得收容物（局外可携带的遗物）并解锁档案；失败不会死亡，但异常会留在场上，局面变得更难。

## 5. 梦层

| 梦层 | 场景 | 专属规则 | 主色 |
|---|---|---|---|
| L0 | 午后四点的游泳馆 | 浅水区减速，深水区敌人减速更多 | 瓷白、水蓝、薄荷 |
| L1 | 黄色办公层 | 灯管每 90 秒集体闪灭 8 秒，只能看清身边 | 芥末黄、米白、灰绿地毯 |
| L2 | 打烊的童年商场 | 广播音乐变速，敌人速度随节拍变化 | 褪色粉、奶油、天蓝 |
| L3 | 永夜学校 | 黑板会写下下一波敌人从哪个方向来 | 夜蓝、黑板绿、粉笔白 |
| L4 | 收容区·失效 | 档案馆本身在崩塌，墙体会移动 | 档案米色 + 警报红 |
| 隐藏 | 云上的卧室 | 无敌人，只有你和最后一份档案 | 晨光金 |

**红色只在 L4 和危险提示中使用**，全作保持这条克制规则。

地图按区块无限生成：由大厅（约 3–4 屏）和宽走廊相连，墙体分段，保证有大片空地可以割草，也有走廊可以利用。

## 6. 记忆物（武器）与安眠物（被动）

**武器（8 件）**

| 武器 | 行为 | 标签 |
|---|---|---|
| 小夜灯 | 身周光环，持续伤害 | 光 / 童年 |
| 纸飞机 | 追踪最近敌人，可穿透 | 纸 |
| 八音盒 | 音符环绕旋转 | 声 / 童年 |
| 泡泡棒 | 泡泡困住敌人后爆裂 | 水 / 童年 |
| 旧录像带 | 周期性“倒带”区域，敌人减速并后退 | 屏幕 |
| 蜡笔 | 身后留下彩色伤害轨迹 | 纸 / 童年 |
| 雨伞 | 前方扇形挥击并挡下弹幕 | 水 |
| 雪花电视 | 随机连锁电流 | 屏幕 / 声 |

**被动（8 件）**：枕头（生命上限）、温牛奶（回复）、闹钟（清醒度）、星星贴纸（暴击）、毛毯（护甲）、旧照片（拾取范围）、小风扇（攻速）、糖果（移速）。

**梦化进化**：条件为武器满级、持有对应被动、处于深梦状态时开宝箱。

- 小夜灯 + 温牛奶 →「不会熄灭的月亮」
- 纸飞机 + 星星贴纸 →「流星信件」
- 八音盒 + 枕头 →「摇篮曲」（敌人原地睡着）
- 旧录像带 + 闹钟 →「永远的周日下午」（时停领域）

## 7. 梦魇与异常

**普通梦魇**：气球人（慢速成群）、无脸同学（标准近战）、嗡鸣体（靠近时吸取清醒度）、毛绒怪（坦克，死后分裂）、雪花电视（远程）、纸人（快速，成排冲锋）、长廊影子（精英，也会穿墙）。

敌人死亡时化作花瓣、纸屑或羽毛散开，这就是标题里的 Bloom。

**异常（原创档案）**

- **NB-017「数羊者」**（温顺）：9 只编号的羊绕场奔跑，必须按 1→9 顺序击破，打错就全体复活。收容物「第十只羊」：投射物 +1。
- **NB-033「无尽生日会」**（游离）：房间里每根燃着的蜡烛都会强化敌人，需穿过烛火将其吹灭。收容物「没许完的愿」：每局复活一次。
- **NB-048「值班的救生员」**（游离，L0 专属）：水位持续上涨，只有会移动的救生椅是安全区，击倒吹哨者即可退潮。收容物「哨子」：周期性击退脉冲。
- **NB-062「另一个你」**（失眠）：以房间中心为轴镜像你的移动。你需要走位，把它引进四盏灯管陷阱。收容物「镜中人」：一个以 30% 伤害复制你武器的分身。
- **NB-000「做梦的人」**：终章，不作为战斗出现。

## 8. 美术指导

- **镜头**：2.5D 俯视约 55°，带轻微移轴景深，让世界看起来像一个被凝视的微缩梦境。
- **光**：大面积柔和的无源光、轻度过曝、体积薄雾；泳池焦散和办公层灯管是两大标志性光源。
- **后处理**（克制使用）：泛光、胶片颗粒、高光晕染（halation）、仅在边缘出现的轻微色散。VHS 跟踪噪点**只在异常事件中出现**，不常驻。
- **可读性优先**：敌人以剪影和柔和轮廓光区分，弹幕不使用与背景相近的颜色；满屏 800 个敌人时，玩家依然要一眼找到自己。
- **字体**：数字使用手写体，档案使用打字机体，界面使用圆润无衬线体。

## 9. 音频

- 隔墙听到的商场轻音乐（muzak），混响随房间大小变化。
- 灯管嗡鸣的响度与清醒度反相关，越深梦越响。
- 八音盒旋律作为全作主题动机，在升级、收容和苏醒时以不同变奏出现。
- 音乐分层叠加，随同屏敌人密度增减声部。

## 10. UI / UX

- **HUD 极简**：左上角梦中时钟（03:14 AM），清醒度是脚下一圈柔光环，经验条是屏幕顶端一道慢慢亮起的地平线。
- **暂停菜单**：一份档案文件，未解锁的内容以涂黑条显示。
- **动效**：全部使用弹簧曲线，门的开合有重量和惯性，伤害数字轻飘飘地浮起再消散。
- **辅助选项**：「温柔模式」关闭画面畸变和镜像异常，屏闪强度可调，支持手柄。

## 11. 局外成长

- **档案馆卧室**：可逐步布置的枢纽场景，收容物会作为摆件出现在房间里。
- **梦尘商店**：永久强化共 12 项，每项 5 级。
- **角色（首批 4 名）**：失眠的少女（均衡）、穿睡衣的男孩（穿模冷却 -30%）、一只布偶猫（体积小、生命低）、临时档案员（开局随机携带一件收容物）。

## 12. 技术方案（建议）

- **技术栈**：TypeScript + Vite + Three.js（WebGL2），正交 / 低视角透视混合的 2.5D 渲染。
- **性能**：
  - 敌人数据用结构化数组（SoA）存储，用 InstancedMesh 批量渲染；
  - 空间哈希做碰撞；
  - 全局流场寻路（每 0.25 秒从玩家位置重算一次），让上千敌人同时绕墙追击；
  - 投射物、伤害数字和粒子全部对象池化；
  - 60Hz 固定步长模拟，渲染插值。
- **存档**：localStorage；之后可用 Tauri 打包为桌面版。
- **性能目标**：集成显卡上同屏 1000 敌人 + 300 投射物保持 60fps，首屏加载不超过 3 秒。

## 13. 数值基线（首版，供调优）

- 玩家移速 4.2，生命 100，受击后无敌 0.5 秒。
- 同屏敌人上限 = 60 + 60 × 分钟，封顶 900；敌人生命倍率 = 1 + 0.12 × 分钟。
- 升到第 n 级所需经验 = ⌊6 × n^1.35⌋，目标在 15 分钟时约 30 级。
- 武器与被动各 6 格，单件满级 8 级。

## 15. 风险与对策

- **有墙地图挤压割草空间** → 大厅要足够大；墙体靠近玩家时半透明化；走廊宽度不少于 3 个身位。
- **诡异感劝退** → 默认不使用跳吓，提供温柔模式；可爱的物件与空旷的空间形成反差，而不是直接惊吓。
- **满屏特效降低可读性** → 设定特效亮度预算；玩家永远是画面里最亮的轮廓。
- **范围膨胀** → 严格先完成 M1 垂直切片，再扩展内容。
- **原创性** → 所有异常、梦层与角色均为原创设计，只借用“阈限空间”和“收容档案”这类氛围语汇，不使用任何现有作品的编号、名称或角色。
