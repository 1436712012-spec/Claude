# 《守夜炮 Nightwatch Flak》游戏规划

> 类型：横版 2D 防空射击（坦克对空）｜平台：浏览器（WebGL2，单个 HTML）｜状态：规划阶段
> **修订重点（V1.1）**：以"**战斗爽**"和"**精美绝伦的画面与特效炫技**"为最高优先级。原有四大机制不变，新增第 3.5 节"战斗手感栈"，第 6 节扩写为画面与特效，技术方案与里程碑相应调整。

---

## 1. 一句话构想

**从黄昏守到黎明。** 你驾驶一辆老式防空坦克，守护身后山谷小镇的灯火。一夜 8 个小时就是 8 波攻势，天空颜色从橙紫色黄昏慢慢变成深蓝的午夜，最后变成粉金色的黎明。**天亮时还亮着的灯有多少，就是你的成绩。**

和“炮管对准、点击、飞机爆炸”的常见做法不同，本作的核心是**用炮弹在天空中“布置”防线**：定时引信、高射烟云、风和光，四套系统叠在一起，让每次开火都是在空间和时间上做一次判断。

---

## 2. 核心机制（四个特色支柱）

### 支柱 A：定时引信 —— 你决定炮弹在哪里爆炸
- 按住开火键时，准星外圈的**引信环**会逐渐扩大，表示爆炸距离；松开时炮弹就以这个距离射出。
- 炮弹飞到设定距离后**空爆**，生成破片球。距离判断越准，伤害越高。
- 也可以轻点直射，靠直接命中造成伤害。直接命中伤害高但很难打中，适合打慢速的大目标。
- 设计意图：把“瞄准”从二维（角度）扩展到三维（角度 + 距离 + 提前量）。

### 支柱 B：高射烟云 —— 爆炸会留在天上
- 每次空爆会留下一团黑色烟云，持续 4–6 秒，期间**飞机穿过就持续掉血**。
- 多团烟云叠在一起会形成“弹幕墙”，可以预先封锁轰炸机的航线。
- 代价是**烟云也会挡住你的视线**，布得太密就看不见后面来的敌机。
- 烟云会**随风漂移**（见支柱 C），过一会儿就会离开你原本想封锁的位置。

### 支柱 C：风 —— 天空是有流动的
- 每波开始时随机生成风向和风力，风力在波次中途会缓慢变化（用 Perlin 噪声驱动）。
- 风会影响炮弹弹道、烟云漂移、伞兵落点，以及坠落残骸的轨迹。
- HUD 上有一面实时飘动的风向旗，旗面的抖动幅度对应风力。

### 支柱 D：光 —— 夜里你看不见它们
- 从第 3 波起天黑。屏幕上会叠一层黑暗遮罩，飞机**只在被照亮时可见**。
- 光源有四种：
  1. **探照灯**：右键控制方向，消耗电量。照到飞机时会“锁定”，持续照亮一段时间。
  2. **曳光弹**：每第 N 发炮弹会在弹道上留下一道光痕。
  3. **爆炸闪光**：空爆会短暂照亮周围一片天空。
  4. **燃烧的残骸**：被击落的飞机坠落时会照亮航线上的其他敌机。
- 引擎声采用**立体声定位**，夜里可以“听声辨位”。

## 3. 辅助机制

| 机制 | 说明 | 带来的玩法 |
|---|---|---|
| 后坐力 | 每次开火坦克会被向后推一段 | 可以借后坐力躲炸弹，“边打边退” |
| 可破坏地形 | 炸弹会炸出弹坑，地形用高度图实时变形 | 坦克在坑里移动变慢、炮管仰角受限，迫使你换位置 |
| 残骸连锁 | 被击落的飞机带着动量坠落，砸中下方敌机或伞兵也算击杀 | “坠机连击”，触发时短暂慢动作，计分倍率提高 |
| 小镇灯火 | 身后每栋房子有一盏灯，被炸中就熄灭 | 有情感的防守目标，评分直观 |
| 补给卡车 | 每波结束后从三张改装卡中选一张 | 每局构筑不同，提高重玩价值 |

## 3.5 战斗手感栈（Juice Stack）——"爽"的验收清单

每次开火和命中按下表**叠加**反馈，逐项勾选，每次改动都回归：

| 层 | 实现 |
|---|---|
| 顿帧 | 轻 2f / 重 5f / 击杀 3f / Boss 部件 8f；只暂停敌人与特效，不暂停玩家输入 |
| 震屏 | "创伤值"模型：`shake = trauma²`，噪声驱动位移与旋转，不同武器注入不同创伤 |
| 后坐力 | 车体后移 + 炮管回缩（弹簧阻尼）+ 履带扬尘（与原有后坐力机制联动） |
| 炮口 | 三层闪光（白核、橙色冲击、烟环）+ 抛壳 + 0.1 秒暖色动态光源 |
| 命中 | 冲击波环（屏幕空间折射）、火花、碎片、受击闪白 |
| 击杀 | 按材质碎裂（金属碎片 / 火球 / 电弧），残骸带物理继续飞行（与残骸连锁联动） |
| 多杀 | 2 秒内 ≥ 3 杀触发 0.4 秒慢动作，镜头轻微推进 |
| 音频 | 低频冲击 + 中频撕裂 + 高频闪烁三层合成，音高随连击微升 |
| 色彩 | 击杀瞬间对比度提升 + 辉光脉冲 |

**新增玩法层**：
- **蓄力炮**：按住开火时，在原有"引信环"基础上可三档蓄力（轻 / 重 / 满蓄贯穿 + 冲击波）。
- **连击槽与过载 Overdrive**：连击槽满后触发 6 秒——时间减缓、炮弹变等离子束、屏幕边缘色散。
- **同轴机枪**：连射，过热时枪管发红并喷蒸汽。
- **肩射导弹**：锁定 3 个目标后齐射，带尾焰与烟迹。

> 取舍：特效越华丽越容易"看不清"，所以画面一律遵守"可读性优先"（见第 6 节）。

## 4. 敌人设计（每种敌人考验一种能力）

| 敌人 | 行为 | 考验 | 出场 |
|---|---|---|---|
| 侦察机 | 高空快速掠过，一旦标记你，几秒后召来炮击 | 优先级判断 | 第 1 时 |
| 水平轰炸机编队 | 排成队形匀速飞行，经过小镇上空时投弹 | 用烟云墙封锁航线 | 第 1 时 |
| 俯冲轰炸机 | 爬升后尖啸着俯冲；拉起时有一段短暂的脆弱窗口 | 把握时机 | 第 2 时 |
| 战斗机 | 低空扫射坦克，飞行轨迹灵活 | 提前量与直射 | 第 3 时 |
| 运输机 | 投下伞兵；打掉伞衣会让伞兵直接摔落 | 风向预判 | 第 4 时 |
| 夜航轰炸机 | 不开航灯，只能靠探照灯或声音发现 | 光与声的运用 | 第 5 时 |
| 飞艇（Boss） | 由多个可破坏部件组成（引擎舱、吊舱炮塔、气囊），部件被毁后行为会改变 | 综合能力 | 第 7 时 |
| 黎明喷气机 | 极快，从屏幕一侧横穿而过 | 最终考验 | 第 8 时 |

**波次导演（Director）**：每一小时有固定的“剧本骨架”（例如某个时间点必定出现俯冲轰炸），再加上根据玩家表现调节的预算池，动态补充敌人，让节奏有起有伏，而不是匀速刷怪。

## 5. 改装卡（初版 12 张示例）

- **双联装**：每次开火射出两发，散布略大
- **近炸引信**：炮弹在敌机附近会自动引爆（降低引信判断的难度）
- **磷光曳光**：所有炮弹都是曳光弹
- **重烟弹**：烟云持续时间 +60%，但更遮挡视线
- **液压悬挂**：后坐力 −70%
- **镜面探照灯**：光束变宽，耗电降低
- **穿甲弹头**：直接命中伤害 ×2
- **防空警报**：敌机出现前 2 秒给出方位提示
- **铲刀**：坦克可以填平弹坑
- **连锁引信**：空爆后会再分裂出 3 枚小破片弹
- **灯塔守望者**：小镇熄灭的灯每波恢复 1 盏
- **逆风装药**：炮弹受风影响 −80%

可以叠加组合，例如“重烟弹 + 磷光曳光”：烟云墙被曳光照亮，形成一道发光的屏障。

## 6. 画面与特效（本作重点）

### 6.0 渲染管线与特效清单

渲染全部迁移到 **WebGL2 + HDR（RGBA16F）**：

```
① 场景绘制到 HDR 帧缓冲（批处理精灵、地形、实例化粒子）
② 2D 动态光照：法线 + 多光源（炮口、爆炸、探照灯、曳光弹）
③ 屏幕空间效果：冲击波折射、热浪、体积光、雾
④ Bloom：双 Kawase 模糊链
⑤ 色调映射 + 色彩分级
⑥ 后期：色差（受击增强）、暗角、颗粒、抗锯齿
⑦ UI 叠加（原生分辨率）
```

| 编号 | 特效 | 技术 | 难度 | 降级方案 |
|---|---|---|---|---|
| V1 | GPU 粒子（≥ 5 万） | 纹理存状态 + 实例化渲染 | ★★★★ | CPU 粒子 + 上限 |
| V2 | 流体烟与火 | 2D 稳定流体或曲线噪声平流 | ★★★★★ | 预烘焙烟雾精灵 |
| V3 | 冲击波折射 | 位移贴图环 | ★★ | 白色环 |
| V4 | 可破坏地形（与原弹坑机制合并） | 高度图 / 位掩码 + 爆炸挖坑 + 碎石 | ★★★★ | 预设弹坑贴图 |
| V5 | 飞机碎裂与残骸 | Voronoi 碎片 + 简单刚体 | ★★★★ | 预切碎片 |
| V6 | 等离子 / 电弧 | 分形折线 + 辉光 | ★★★ | 直线 + 辉光 |
| V7 | 动态光照 + 法线（与原探照灯机制合并） | 多光源 2D 光照 | ★★★★ | 单光源 |
| V8 | 体积光 / 大气 | 径向模糊 | ★★★ | 关闭 |
| V9 | 慢动作与过载视觉 | 时间缩放 + 色差 + 速度线 | ★★★ | 仅慢动作 |
| V10 | Boss 飞艇演出 | 多部件 + 破坏阶段 + 镜头调度 | ★★★★★ | 简化部件 |
| V11 | 天气（暴雨、闪电、云海） | 粒子 + 光照联动 | ★★★ | 关闭 |

**优先级**：P0 = V1、V3、V7 与手感栈；P1 = V4、V5、V6、V8、V9；P2 = V2、V10、V11。

### 6.0.1 性能预算与画质

- 1080p 目标 60 fps，中端笔记本集成显卡不低于 45 fps。
- 粒子：高档 5 万 / 中档 2 万 / 低档 5 千；后期总 GPU 耗时 ≤ 4 ms。
- 运行时监测帧时间，自动逐级关闭 V2、V8 并降低粒子上限。
- **光敏与可读性**：全屏闪光不超过每秒 3 次，提供"减少闪光 / 震动"总开关；敌方弹幕始终高对比并带轮廓；提供特效强度滑块。

### 6.1 原有视听风格（沿用）

- **剪影绘本风**：坦克、飞机、小镇都用纯黑剪影和高光描边，画在渐变天空上。全部由代码程序化绘制，**不依赖任何外部图片**。
- **天空时间轴**：8 个关键色调帧之间插值过渡（黄昏橙 → 紫 → 深蓝 → 午夜黑蓝 → 微光蓝 → 粉金），并加上星空、月亮和云层视差。
- **光照**：由 6.0 的 WebGL2 管线实现（多光源 + 法线 + 夜间黑暗遮罩"挖洞"），爆炸闪光用加色混合叠加。
- **音频**：全部用 WebAudio 程序化合成，包括炮击低频冲击、俯冲尖啸（频率随下降速度升高）、防空警报、立体声定位的引擎声。
- **手感（Juice）**：屏幕震动、命中瞬间短暂停顿（hitstop）、坠机连击慢动作、炮口火光、弹壳抛出。

## 7. 技术方案

### 7.1 技术选型
- **WebGL2（HDR 管线）+ 原生 ES Modules，零运行时依赖。** 画面部分由 `gfx/`（批处理、GPU 粒子、光照、后期）承担，UI 仍可用 Canvas 2D 叠加。
- 开发时用任意静态服务器运行（例如 `python3 -m http.server`）；另写一个构建脚本，把所有模块内联成单个 `dist/nightwatch.html`，方便分享或发布成网页。
- 测试用 Playwright 做无头冒烟测试，再用 Node 跑固定种子的逻辑模拟测试。

### 7.2 架构
```
src/
  main.js              入口，游戏状态机（标题 / 游戏中 / 补给 / 结算）
  core/
    loop.js            固定步长 60Hz 更新 + 插值渲染
    input.js           键鼠输入（预留触屏接口）
    rng.js             可设种子的随机数（保证测试可复现）
    noise.js           Perlin 噪声（风、地形）
    pool.js            对象池（炮弹、粒子、烟云）
  world/
    terrain.js         高度图地形，支持弹坑变形与碰撞查询
    wind.js            风场
    sky.js             天空时间轴、星空、云层视差
    town.js            小镇与灯火
  entities/
    tank.js            移动、炮塔、后坐力、引信充能
    shell.js           弹道（重力 + 风 + 引信）
    flak.js            空爆与烟云（持续伤害、漂移、遮挡）
    wreck.js           残骸物理与连锁判定
    enemies/           各敌人的状态机，每种敌人一个文件
  systems/
    director.js        波次导演（剧本骨架 + 动态预算）
    lighting.js        黑暗遮罩与光源合成
    collision.js       空间哈希宽相 + 圆形/线段窄相
    upgrades.js        改装卡定义与效果挂钩
    audio.js           WebAudio 合成器
    fx.js              屏幕震动、hitstop、慢动作、粒子
  ui/
    hud.js             引信环、风向旗、电量、灯火计数
    screens.js         标题、补给选卡、结算画面
tools/
  build.mjs            把模块内联成单个 HTML 文件
tests/
  sim.test.mjs         固定种子逻辑模拟（例如“无操作时第 1 波会损失几盏灯”）
  smoke.spec.mjs       Playwright：页面能加载、能开火、无控制台报错
```

### 7.3 关键算法要点
- **弹道**：半隐式欧拉积分，`v += (g + wind·k) dt`。引信按飞行距离累计计算，而不是按时间。
- **烟云伤害**：每帧对“飞机 × 烟云”做圆形重叠检测，借助空间哈希把复杂度控制在接近 O(n)；伤害与重叠深度成正比。
- **地形变形**：用 `Float32Array` 存储高度图，弹坑是一个余弦形状的减法核；坦克的倾角由左右两个履带接触点的高度差计算。
- **夜间可见性**：每架飞机记录一个 `litUntil` 时间戳，渲染和瞄准辅助只对“当前被照亮”的目标生效。
- **难度曲线**：导演的预算公式为 `budget(t) = base(hour) × performanceFactor`。表现因子取近 30 秒的灯火损失率和命中率，限定在 0.8–1.25 之间，避免难度剧烈波动。

| 阶段 | 内容 | 验收标准 |
|---|---|---|
| **M0 骨架** | 游戏循环、WebGL2 初始化与精灵批处理、输入、天空渐变、地形、坦克移动与炮塔瞄准 | 能开动坦克并转动炮管，帧率稳定 60 |

| **M1.5 光与粒子** | HDR 管线、Bloom、冲击波折射、动态光照、GPU 粒子（V1、V3、V7） | 一发炮弹的画面可当壁纸；同屏 5 万粒子 ≥ 60 fps |
| **M2 敌人与波次** | 侦察机、俯冲轰炸机、战斗机、运输机和伞兵；导演系统；小镇灯火；第 1–4 时 | 可以完整打完前半夜 |

| **M4 物理演出** | 可破坏地形、后坐力、残骸连锁与慢动作 | 出现可复现的“坠机连击” |
| **M5 构筑与流程** | 补给卡车、12 张改装卡、标题和结算画面、本地最高分 | 完整一夜（8 波）可以通关 |
| **M6 视听打磨** | WebAudio 音效、立体声定位、屏幕震动/hitstop、粒子、天空细节 | 手感测试达标 |

**建议节奏**：先完成 M0 + M1 + M1.5 作为“垂直切片”，确认**开炮爽不爽、画面够不够惊艳**，再横向扩展内容。如果手感与画面不成立，后面堆再多内容也救不回来。其余里程碑中新增的特效（V4–V11）按 6.0 的优先级穿插进 M2–M7。

## 9. 风险与对策

| 风险 | 对策 |
|---|---|
