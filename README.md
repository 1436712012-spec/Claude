# 夹层 LIMINAL

一款单文件、零外部图片的卡牌对战游戏。题材是收容档案、后室与梦核：你是收容机构的外勤特工，被派进一个会「下沉」的梦境异常地带，去见三位守门人——以及上一支消失的小队留下的东西。

**直接游玩**：用浏览器打开 [`liminal.html`](liminal.html)。手机竖屏优先，桌面同样可玩（宽屏会多出战斗记录与卡牌详情侧栏）。

## 玩法速览

| 系统 | 规则 |
| --- | --- |
| 骨架 | 英雄 30 血；法力水晶每回合 +1（上限 10）；场上最多 7 个随从；手牌上限 10；卡组 30 张，同名 ≤2、传说 ≤1；开局换牌，后手得「旧硬币」；牌库抽空后疲劳递增 |
| 关键词 | 嘲讽、冲锋、突袭、战吼、亡语、圣盾、潜行、剧毒、冻结，以及原创的收容、褪色、回响、暗袭、坠入夹层、场地 |
| 理智 | 上限 10，开局满值，每回合 +1。带 ⟁ 的牌额外支付理智、同费更强。理智 ≤3 进入「动摇」，手里会混进不存在的牌；归 0 时每回合开始受到 2 点伤害 |
| 梦深 | 双方共用。消耗的理智、特定卡牌与每个回合的流逝都会推高它。达到 12 进入第 1 层，达到 26 进入第 2 层，不可逆；见底后进入「闭店时间」 |
| 第 0 层 · 黄墙走廊 | 无特殊规则 |
| 第 1 层 · 无人泳池 | 所有治疗翻倍；随从攻击后 50% 漂移到相邻位置 |
| 第 2 层 · 深夜商场 | 所有随从 +1 攻击；每个回合结束时随机摧毁一个生命值最低的随从 |
| 收容 | 消灭敌方随从（不触发亡语），洗入你牌库顶部 3 张中，带 3 回合突破倒计时。及时打出，它为你而战；否则它在敌方场上突破复活 |
| 褪色 | 在手里每多留一回合，牌面就有一个词变得模糊；3 回合后效果随机化（可能很好，也可能什么都没有），费用 -1 |

**操作**：轻触手牌 → 轻触战场或目标；也可以直接拖。按住手牌左右滑动放大阅读，松手即选中。轻触发光的随从 → 轻触敌人进行攻击，或从随从拖向目标。长按任何东西查看详情。桌面可按 `E` 结束回合、`Esc` 关闭浮层。

## 内容

- **64 张收藏卡**：收容站 18（控制：嘲讽、冻结、护甲、收容）、后室层级 18（场地、潜行、剧毒、暗袭、坠入夹层）、梦核 18（复制、偷取、回响、褪色）、中立 10。另有 6 张守门人专属牌，击败对应守门人后解锁进收藏。
- **3 位特工**（英雄技能各不相同）与 **3 位守门人**（专属卡组、技能、台词与 AI 性格：控场 / 节奏 / 狂暴）。
- **3 套预组**与卡组构筑（按阵营、费用、稀有度筛选，法力曲线，自动保存在本机；本机存储不可用时保存在会话内存中）。
- **档案**：每张牌的风味文字都是一段收容档案、褪色日记或无线电残句，按时间线排列后是外勤组「回声-4」消失的完整经过。最后一页需要击败全部三位守门人。
- 所有卡图、头像、卡背都由代码绘制（参数化 SVG，空闲时栅格化）；所有声音都由 Web Audio 实时合成。

## 开发

```bash
node tools/build.mjs          # 产出 liminal.html（以及 dist/ 下的片段版）
node tools/cardtest.mjs       # 逐卡规则测试：每张牌的效果与文字一致
node tools/sim.mjs 360        # 无头 AI 对战：稳定性与平衡统计
node tools/cardstats.mjs 300  # 单卡出场胜率
node tools/e2e.cjs out --full # 浏览器完整对局冒烟（手机视口，控制台必须无报错）
node tools/interact.cjs out   # 真实指针事件的交互测试
node tools/perf.cjs 2 30000   # CPU 降速下的帧时间
```

源码结构：

| 文件 | 作用 |
| --- | --- |
| `src/js/00-base.js` | 常量、关键词表、带种子的随机数、克隆 |
| `src/js/10-engine.js` | 纯数据规则引擎：可克隆、确定性，输出「事件 + 快照」流 |
| `src/js/20-cards.js` | 卡池（规则脚本、故事碎片、卡图参数） |
| `src/js/25-heroes.js` | 特工、守门人、预组、卡组校验 |
| `src/js/30-ai.js` / `32-aiworker.js` | 克隆模拟 + 性格权重 + 斩杀搜索；在 Web Worker 中运行 |
| `src/js/40…90` | 存储、音频合成、卡图生成、粒子与特效、牌面渲染、对局控制、切层演出、菜单、启动 |
| `src/css/main.css` | 视觉系统：所有尺寸基于 `--u`（游戏列宽的 1%） |
