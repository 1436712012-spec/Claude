# 星图兽 · Astral Bestiary

一个浏览器游戏：在夜空中连起星辰，连成的星座会苏醒成为生物。它的几何形状就是它的基因。

打开 `star-beasts/index.html` 即可游玩（无构建步骤、无依赖，字体来自 Google Fonts，离线时自动回退）。

## 玩法

1. **观星**：按住一颗星拖向附近的另一颗星，或依次点选星星。右侧「星象推演」随每一笔实时重算。
2. **点睛**：星线沿 BFS 顺序逐段点燃，星座以弹簧骨骼跃出夜空、睁开眼睛。收入图鉴后，它的星座会永久留在你的天空里。
3. **星战**：最多三只出战，对抗每夜来袭的「蚀星」。胜利后星力上限 +1、出战者升级、二十八宿轮转。

## 几何即基因

| 几何特征 | 影响 |
|---|---|
| 星点数 | 体魄（生命） |
| 闭环数 E−V+1 | 护甲；两环以上成「龟」 |
| 锐角（< 55°）| 攻势与暴击 |
| 平均星距、伸长度（PCA） | 迅捷 |
| 镜像对称度（72 条轴搜索） | 灵力与稀有度 凡/灵/玄/天 |
| 星色加权温度 | 元素：雷 › 霜 › 辉 › 焰 › 烬 › 雷 |
| 拓扑（分叉、链、环、对称） | 十种形态与天赋：龙蛇龟蛛蝶鹤鲸狼鹿狐 |

星空的星色与星云色共享同一张噪声温度场，冷区多生雷霜，暖区多生焰烬。
星座重心所在的宿位若在今夜「当空」七宿之内，出战时攻势 +20%、迅捷 +15%。

## 星图码

每只星图兽可导出一串 `xt…` 星图码（量化坐标 + 星色 + 连线 + 校验和，Crockford base32）。在「图鉴」中导入即可得到完全相同的星图兽。

## 代码结构

- `star-beasts/js/engine.js`：数学工具、值噪声、发光贴图缓存、Web Audio 合成音效、粒子特效、星空与背景渲染
- `star-beasts/js/beast.js`：几何分析、命名与传说文本、星图码编解码、`Body` 弹簧骨骼渲染
- `star-beasts/js/game.js`：状态与存档、观星交互、点睛演出、图鉴、星战模拟、主循环

存档保存在浏览器 `localStorage`，键名为 `astral-bestiary-v1`。
