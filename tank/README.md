# 守夜炮 · NIGHTWATCH FLAK

横版 2D 坦克防空射击。从黄昏守到黎明：驾驶一辆防空坦克，守住身后小镇的灯火，撑过 8 波空袭。
浏览器运行（WebGL2），**零运行时依赖**，可打包成单个 HTML 文件。**手机可直接玩，全部武器自动开火。**

## 运行

```bash
# 开发：任意静态服务器（ES Modules 需要 http，不能直接 file://）
python3 -m http.server 8000      # 然后打开 http://localhost:8000/tank/

# 发布：打包成单个 HTML，双击即可玩（也可以发给手机）
node tools/build.mjs             # -> dist/nightwatch-flak.html
```

## 操作

**电脑**

| 输入 | 作用 |
|---|---|
| A / D | 行驶（贴地倾斜） |
| 鼠标 | 瞄准；**准星位置就是炮弹的爆点** |
| 左键 按住 / 松开 | 蓄力 / 开炮。点按=直射弹；按住分三档空爆弹 |
| 右键 或 F | 同轴机枪（会过热） |
| Q | 手动提前齐射导弹（已获得时） |
| E | 过载（连击槽满后）：敌人减速、炮弹变等离子、辅助武器冷却加速 |
| 空格 | 喷口跳跃 |
| **T** | 循环切换：手动瞄准·手动开火 → **自动瞄准**·手动开火 → **全自动**（设置里也可选） |
| 1 / 2 / 3 | 在武器三选一界面选择 |
| Esc / P | 暂停 / 设置 |

**手机（横屏，默认全自动）**：左半屏浮动摇杆行驶、**上推 = 跳跃**；右半屏**拖动手指 = 指定瞄准点**（准星在手指上方，不挡视线），
松手则自动瞄准最危险的目标；右下角跳跃 / 过载按钮，右上暂停。首次触屏会请求全屏并尝试锁定横屏；竖屏时提示旋转。

## 武器库（12 把，每把 5 级）

开局三选一，**每波肃清后再三选一**（新武器或升级，基础炮与机枪也可强化）。辅助武器全部自动开火；过载时冷却 ×1.6。

| 武器 | 机制 | 视觉招牌 |
|---|---|---|
| 高射炮 | 蓄力三档空爆、烟云持续伤害、受风影响 | 蓄力环、爆点范围圈 |
| 同轴机枪 | 压制近身目标，会过热 | 曳光、抛壳 |
| 蜂群导弹 | 齐射追踪导弹，优先最危险目标 | 烟迹、尾焰 |
| 特斯拉电弧 | 闪电在敌机间连锁跳跃并麻痹 | 分形闪电带分叉，车尾线圈放电 |
| 磁轨炮 | 蓄力后贯穿整条直线，选线时优先穿透最多目标 | 色散光束、折射条纹、子弹时间 |
| 引力奇点 | 黑洞吸住飞机/炸弹/粒子，末尾坍缩爆炸 | 吸积盘、引力透镜、GPU 粒子被吸入 |
| 棱镜激光 | 多色光束编织缠绕，灼烧并贯穿沿线敌机 | 彩虹编织光束、棱镜星芒 |
| 烟花榴弹 | 圆环/双环/螺旋/爱心/土星/垂柳，每颗星火造成伤害 | 参数曲线爱心烟花、拖尾星火 |
| 蜂群无人机 | 环绕坦克，自动出击扫射并撞击 | 带光迹的集群 |
| 音爆脉冲 | 感知威胁时摧毁炸弹与子弹、震退敌机 | 大范围折射环 |
| 轨道离子炮 | 锁定敌群，延迟后光柱从天而降，3 级起横扫 | 锁定标记、光柱、地面冲击 |
| 高射弹幕 | 连发一串空爆弹排成火墙 | 连环空爆 |

## 技术概览

- **渲染**：WebGL2 HDR 管线（无 `EXT_color_buffer_float` 时回退到半精度）。全部美术由 SDF 在着色器里程序化绘制
  （逐像素法线 + 多光源），程序化合成器黄昏背景，双 Kawase 辉光、冲击波折射、**引力透镜**、体积光、色差、ACES 色调映射。
- **GPU 粒子**：Transform Feedback，6.5 万粒子；重力、阻力、湍流、风、地形碰撞、**引力井吸引**全在 GPU。
- **手感栈**：顿帧、创伤值震屏、后坐力、炮口闪光、冲击波、碎片与火花、多杀慢动作、镜头推进。
- **自动炮手**（`sim/gunner.js`）：选目标、预判、风偏补偿、自动决定蓄力档位；也驱动标题画面的演示机器人。
- **程序合成音频**：炮声三层叠加、程序生成混响、随战斗强度分层的合成器配乐，每把武器各有音效。
- **手机适配**：多点触控（Pointer Events）、HUD 随屏幕高度缩放、起始渲染分辨率 0.75 + 自适应画质、
  触控 `touch-action: none`、全屏与横屏锁定。

## 目录

```
src/core    数学、RNG、输入（键鼠 + 触屏）
src/gfx     GL 封装、着色器、SDF 实例批处理、GPU 粒子、渲染管线
src/sim     地形、坦克、基础武器、武器库(arsenal)、自动炮手(gunner)、敌人、小镇、特效(fx)、天空、波次与总控(game)
src/audio   WebAudio 合成
src/ui      HUD（含武器栏、三选一、触控界面）、设置面板
tools/      build.mjs 单文件打包；shot / planes / sky / title / arms 无头截图工具
tests/      interaction.mjs（键鼠）、touch.mjs（手机多点触控）
```

## 测试

```bash
export NODE_PATH=$(npm root -g)          # 需要 Playwright
node tests/interaction.mjs               # 键鼠：驾驶/瞄准/蓄力/机枪/跳跃/选武器/导弹/暂停/死亡重开/T 切换
node tests/touch.mjs                     # 手机：点按开始/点卡牌/摇杆/上推跳跃/双指/自动开火/过载/暂停
node tools/arms.mjs /tmp/arm             # 每把武器单独上场，等招牌效果出现再截图（同时验证每把都会触发）
```

URL 参数：`?fps=1` 显示帧率；`?autostart=1&bot=1` 机器人自动游玩；`?arms=all&lv=3`（或 `arms=tesla,rail`）直接给武器；
`?auto=0/1` 强制关/开全自动；`?seed=xxx`、`?dpr=1`、`?noadapt=1`。

## 已验证 / 未验证

已验证（无头 Chromium + SwiftShader 软件渲染）：
- 着色器全部编译、无控制台报错；单文件构建经 `file://` 运行。
- 键鼠测试 20 项、**手机多点触控测试 18 项**全部通过。
- **10 把辅助武器逐个验证都会在数秒内触发招牌效果**，并逐张人工检查了画面（据此收敛了多把武器的过曝）。
- 机器人带新武器库整局浸泡到第 7 波，每波自动获取武器，零报错。

**未验证**：
- **真实手机与真实 GPU 的帧率**（软件渲染只有几帧每秒；iOS Safari 的全屏/横屏锁定行为各机型不同）。
- 声音听感（无声卡环境，只确认合成代码无报错）。
- 人工游玩的难度与武器平衡。
- "手机当遥控器、电脑当屏幕"的配对模式**未实现**（需要中继服务器或 WebRTC 信令，无法在零依赖单文件内完成）。
