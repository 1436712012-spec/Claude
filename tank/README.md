# 守夜炮 · NIGHTWATCH FLAK

横版 2D 坦克防空射击。从黄昏守到黎明：驾驶一辆防空坦克，守住身后小镇的灯火，撑过 8 波空袭。
浏览器运行（WebGL2），**零运行时依赖**，可打包成单个 HTML 文件。

## 运行

```bash
# 开发：任意静态服务器（ES Modules 需要 http，不能直接 file://）
python3 -m http.server 8000      # 然后打开 http://localhost:8000/tank/

# 发布：打包成单个 HTML，双击即可玩
node tools/build.mjs             # -> dist/nightwatch-flak.html
```

## 操作

| 输入 | 作用 |
|---|---|
| A / D | 行驶（贴地倾斜） |
| 鼠标 | 瞄准；**准星位置就是炮弹的爆点** |
| 左键 按住 / 松开 | 蓄力 / 开炮。点按=直射弹；按住分三档空爆弹（越久越大，满蓄会过载发光） |
| 右键 或 F | 同轴机枪（会过热） |
| Q | 导弹：3 发自动锁定准星附近的敌机 |
| E | 过载（连击槽满后）：敌人减速、炮弹变等离子、伤害提升 |
| 空格 | 喷口跳跃 |
| Esc / P | 暂停 / 设置（特效强度、震屏、辉光、减少闪光、音量、画质） |

风会吹偏炮弹、也会把烟云吹走，注意屏幕上方的风旗。空爆后留下的烟云会持续伤害穿过它的飞机。

## 当前实现（M0 + M1 + M1.5 垂直切片）

- **渲染**：WebGL2 HDR 管线。全部美术由 SDF 在着色器里程序化绘制（逐像素法线 + 多光源），
  程序化合成器黄昏背景（太阳、月亮、星空、云、三层山脉、三层霓虹城市），
  双 Kawase 辉光、冲击波折射、体积光、色差、ACES 色调映射。
- **GPU 粒子**：Transform Feedback，6.5 万粒子环形缓冲；重力、阻力、湍流、风、地形碰撞（高度纹理）全在 GPU。
- **手感栈**：顿帧、创伤值震屏、后坐力、三层炮口闪光、冲击波、碎片与火花、多杀慢动作、镜头推进。
- **玩法**：蓄力空爆 + 烟云持续伤害 + 风；轰炸机 / 侦察机 / 俯冲机；坠毁残骸连锁击杀；
  可被炸出弹坑的地形；小镇灯火；8 波，天空从黄昏一路变到黎明；过载、导弹、机枪。
- **其它**：程序合成音频（炮声三层叠加、程序生成混响、随战斗强度分层的合成器配乐）、
  标题画面背后是自动演示的机器人、自适应分辨率、设置持久化。

## 目录

```
src/core    固定步长数学、RNG、输入
src/gfx     GL 封装、着色器、SDF 实例批处理、GPU 粒子、渲染管线
src/sim     地形、坦克、武器、敌人、小镇、特效(fx)、天空、波次与总控(game)、演示机器人
src/audio   WebAudio 合成
src/ui      HUD(Canvas2D)、设置面板
tools/      build.mjs 单文件打包；shot/planes/sky/title.mjs 无头截图工具
tests/      interaction.mjs 真实键鼠冒烟测试
```

## 测试

```bash
export NODE_PATH=$(npm root -g)          # 需要 Playwright
node tests/interaction.mjs               # 驾驶/瞄准/蓄力/机枪/跳跃/导弹/暂停/死亡重开
node tools/shot.mjs --query "autostart=1&bot=1&noadapt=1&dpr=1" --at 5,15,30 --out /tmp/shot
```

URL 参数：`?fps=1` 显示帧率，`?bot=1&autostart=1` 机器人自动游玩，`?seed=xxx`，`?dpr=1`，`?noadapt=1`。

## 已验证 / 未验证

已验证（无头 Chromium + SwiftShader 软件渲染）：着色器全部编译、整局流程（8 波机器人浸泡测试无报错）、
真实键鼠输入测试 17 项全过、单文件构建经 `file://` 运行无报错、各昼夜阶段的画面截图。

**未验证**：真实 GPU 上的帧率（软件渲染只有 1–3 fps，不代表真实表现；已内置自适应分辨率与画质档位）、
声音的听感（无声卡环境，只确认合成代码无报错）、人工游玩的难度平衡、手柄与触屏（未实现）。
